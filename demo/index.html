A figure that reacts

hapto — state in, drawing out. No timeline.

The curve below is f(x) = x², and the red point sits on it. Drag the slider and the point follows: nothing is playing, and no time passes between one position and the next. The figure is a function of one value.

The prose can set it too. At x = 0 the point is at the bottom of the curve; at x = 2 it has climbed to 4; by x = 4.5 it is past 20. Hover any of those.
