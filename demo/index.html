A figure that reacts

hapto 2.0 — a document in, a drawing out. No timeline.

The curve below is f(x) = x² − 2x. The tangent at the point is the limit of the dashed secants: pull the second point towards the first, or shrink h, and the two slopes meet. Both points can be dragged; the first stays on the curve because its drag only sets x.

The prose can set the state too. At x = 1 the tangent is flat; at x = −0.5 it falls steeply, and at x = 2.5 it climbs. Hover any of those.
